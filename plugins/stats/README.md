# stats

Model usage analytics for tokens, cost, cache efficiency, and generation speed.

## Install

Install **stats** from **Settings → Plugins → Available**, then enable it.

| Field | Value |
| --- | --- |
| Version | 0.2.9 |
| requiresCore | 0.28.53 |
| requiresSharedApi | none |

This plugin has no configuration fields.

See the [Usage Statistics page in the Elowen user manual](https://github.com/dragocz95/elowen/blob/main/docs/site/46-stats-plugin.md).
