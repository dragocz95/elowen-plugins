# browser

Browser automation for linked accounts with account-private profiles, live takeover, screenshots, accessibility navigation, and enforcing network controls.

## Install

Install **browser** from **Settings → Plugins → Available**, then grant it to accounts that should use it.

| Field | Value |
| --- | --- |
| Version | 0.4.9 |
| requiresCore | 0.28.50 |
| requiresSharedApi | none |

Configure the browser executable, session and user limits, timeouts, viewport and viewer limits, Chrome memory and target limits, proxy limits, and the private-network allowlist in the plugin settings.

See the [Browser page in the Elowen user manual](https://elowen.run/docs/browser-plugin).
