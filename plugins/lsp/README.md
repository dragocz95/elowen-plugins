# lsp

Language-server diagnostics, definitions, references, hover information, and document or workspace symbols.

## Install

Install **lsp** from **Settings → Plugins → Available**, then enable it.

| Field | Value |
| --- | --- |
| Version | 0.3.0 |
| requiresCore | 0.28.50 |
| requiresSharedApi | none |

Configure diagnostics availability and the language-server idle timeout in the plugin settings.

See the [Code Tools page in the Elowen user manual](https://github.com/dragocz95/elowen/blob/main/docs/site/39-code-tools.md).
